# 🌦️ Weather App

A responsive **Weather App** built using **HTML, CSS, and JavaScript** that allows users to search for any city and view real-time weather information. This project demonstrates API integration, DOM manipulation, and responsive front-end design.

---

## 🚀 Features

- Search weather by city name
- Display current temperature
- Show humidity level
- Show wind speed
- Dynamic weather icons based on conditions
- Clean and responsive user interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript 
- Weather API
